# Meta Ads Performance Dashboard Report

## Project Overview

This project analyzes Meta (Facebook & Instagram) advertising campaign performance using Power BI.

The dashboard helps marketing teams monitor campaign performance, identify high-performing audience segments, compare advertising metrics, and make data-driven decisions.

The project was developed using Power Query for data transformation, DAX for calculations, and interactive Power BI visualizations.


### Business Problem / Business Questions Answered:

1. Which campaign generated the highest CTR?

2. Which audience segment performed best?

3. Which country generated the highest impressions?

4. Which ad type produced the highest conversion rate?

5. How did campaign performance change over time?

6. Which campaigns should receive additional budget?

7. Which campaigns should be optimized?

8. Which age group generated the highest engagement?

9. Which platform performed better?

10. What marketing insights can improve ROI?

## Project Objectives

- Analyze campaign performance
- Monitor KPIs
- Compare campaign effectiveness
- Identify top-performing audience segments
- Improve marketing decision making

## Key Insights

- Female audiences generated the highest impressions.
- CTR increased during mid-year campaigns.
- Certain countries consistently outperformed others.
- Facebook campaigns produced more clicks than Instagram.
- Higher budgets did not always produce better conversions.


## Recommendations

- Increase budget for high-performing campaigns.
- Pause low CTR campaigns.
- Target the best-performing audience groups.
- Optimize campaigns with high CPC.
- Focus advertising spend on top-performing regions.
