# 📊 Meta Ads Performance Dashboard | Power BI

> **An interactive Power BI dashboard built to analyze Meta (Facebook & Instagram) advertising campaigns using Power Query, DAX, and advanced visualizations.

This project transforms raw marketing campaign data into meaningful business insights through KPI tracking, audience analysis, campaign performance evaluation, and geographical reporting.**

The dashboard provides a comprehensive analysis of Meta Ads campaigns by combining multiple marketing metrics into a single interactive reporting solution.

It enables marketers and analysts to:

- Monitor campaign performance
- Analyze audience engagement
- Compare campaign efficiency
- Track KPIs
- Explore geographical distribution
- Evaluate advertising ROI

## 🧮 DAX Measures

Several DAX measures were created to calculate business KPIs.

| Measure | Purpose |
|----------|----------|
| Total Impressions | Sum of impressions |
| Total Clicks | Sum of clicks |
| CTR | Click Through Rate |
| CPC | Cost Per Click |
| CPM | Cost Per 1000 Impressions |
| Conversion Rate | Conversion Percentage |
| Purchase Rate | Purchase Percentage |
| Total Budget | Overall Budget |
| Average Budget | Average Budget per Campaign |
| Engagement Rate | Audience Engagement |

📄 Complete DAX formulas are available inside:

>DAX/DAX_Measures.md

## 💡 Business Insights

Some key findings from the dashboard include:

- High-budget campaigns generated the highest impressions.
- Younger audiences showed higher engagement.
- Certain countries delivered better conversion rates.
- Peak engagement occurred during specific hours.
- CTR varied significantly between campaign types.
- Budget allocation influenced campaign efficiency.
